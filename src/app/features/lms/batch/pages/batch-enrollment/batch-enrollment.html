📌 Operator Guidelines

Batch Enrollment Operations Guide

Follow these steps to enroll students or manage the cohort membership securely:

01

Search Student Records

Type in the student's full name or email address. The system queries the database asynchronously with a 400ms buffer.

02

Verify Student Details

Ensure the student profile and email domain correspond exactly to the registered applicant details to prevent errors.

03

Add Cohort Linkage

Click the "+ Enroll" action button. This creates a link in the LMS batch registry, granting immediate dashboard access.

04

Audit Cohort Roster

Verify enrolled rows. If a student is assigned to the wrong batch, click the "Remove" button and confirm the browser prompt.
