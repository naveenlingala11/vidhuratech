System Control Panel - Technical Operations Manual

1. Administrative Command Directory

The System Control Panel provides centralized routing to VidhuraTech’s operational modules. Commands are organized into five key administrative areas:

  • Users Directory & Access: Oversee student profiles in the Users Directory, provision coordinator accounts with Create Employee, and manage registrations in the Admissions Panel.
  • LMS Schedule Cohorts: Build classrooms via the Batches Manager, publish broadcasts using Batch Communication, manage syllabi through the Courses Database, and load Excel files via Bulk Course Upload.
  • CRM & Platform Operations: Monitor inbound student queries in the Leads Pipeline, empty or restore deleted items from the Recycle Center (Bin), and manage test banks in the Questions Database.
  • Careers & Placements: Configure scrapers in the Companies Directory, publish active vacancies in the Jobs Manager, and verify graduate credentials using the Certificates Verifier.
  • Billing & Invoices: Inspect transaction histories in the Invoice Registry and check collection charts in the Revenue Analytics panel.

2. Sandbox Data Seeding & Operations

For database testing, administrators can trigger the bulk job seeder. Ensure seeder runs comply with standard database parameters:

  • Custom Record Counts: Select a preset chip (100 to 50,000) or enter a custom integer value in the input field. The range slider supports seeding up to 100,000 items in a single run.
  • Clean Ingestion: Enabling the Clear Database First toggle executes a truncate cascade on the jobs table before writing new listings, establishing a clean testing baseline.
  • Seeder Progress Bar: The UI polls the backend every 800ms to update progress (X of Y) and runs a live stopwatch to display elapsed time.

3. Administrative Search & Audit Log Sync

The Control Panel integrates real-time search filtration, diagnostic checkers, and operational logs:

A
Dynamic Filter Routing

Entering terms in the search bar or clicking category pills (e.g. Careers, LMS) instantly filters the modules list to show relevant command cards.

B
Integrated Diagnostics

The panel measures latency by fetching analytics. It dynamically updates the status badge of the Core API Gateway and Database Clusters.

C
Real-Time Audit Trail

The sidebar pulls recent invoices and student billing updates, converting them into audit feed entries (e.g. Payment Received, Invoice Generated).

4. Control Panel Troubleshooting & Diagnostics Runbook

  • Command Directory is Empty: If search filters return a "No matching modules" state, click the "Reset Filters" button to restore all 15 administrative command cards.
  • Diagnostics Indicate Offline: If the Core API Gateway or Database Clusters status shows a red Offline or Disconnected badge, check the backend server logs. Latency values above 500ms indicate network overhead.
  • Bulk Seeding Locks: When seeding 50,000+ test jobs, database transactions may experience lock waiting times. Do not close the browser tab or refresh the dashboard until the seeder modal shows the final completed summary.
