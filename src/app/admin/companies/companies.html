Hiring Partners & Scraper Controls - Administrator Manual

1. Scraper Configuration

The hiring partner board controls which external career pages are automatically scanned for job listings. When adding a new partner, ensure you provide accurate information:

  • Company Name: The official name of the hiring partner (e.g. Google India or Amazon). This matches the brand shown in public job listings.
  • Careers Portal URL: The exact web address of the careers landing page. It must begin with http:// or https://.
  • Integration API Type: Choose the crawler engine that matches the partner's ATS (Applicant Tracking System) framework. Refer to the spec sheet below for details.

2. Crawler Actions & Telemetry

The registry displays real-time health data for each integrated partner board to ensure scrapers run seamlessly:

  • Telemetry Logs: Tracks extraction statistics:
    • Success Logs Shows successful job listing crawls.
    • Failed Logs Shows crawl attempts that failed due to page updates or rate limits.
  • Crawler Status: Shows the active state of the scraper configuration:
    • Monitoring Active. The scheduler scrapes this board at configured intervals.
    • Suspended Paused. No new jobs are crawled. Current jobs remain active.
  • Actions: Use the toggle button to instantly pause or resume a scraper, or the bin button to permanently delete the configuration.

Supported ATS Platforms & URL Spec Sheet

For automated extraction to succeed, your Careers Portal URL must match the ATS format required by the scraper engine:

ATS Platform Required URL Pattern Examples Scraper Behavior
Greenhouse https://boards.greenhouse.io/companyname Queries the Greenhouse API to pull clean JSON listings directly.
Lever https://jobs.lever.co/companyname Queries Lever's public API endpoint for high-speed, structural jobs ingestion.
Workday https://company.wd1.myworkdayjobs.com/Careers Crawls page elements and parses Workday's standard pagination structure.
SmartRecruiters https://careers.smartrecruiters.com/companyname Fetches structural XML and JSON feeds directly from SmartRecruiters.
Naukri Feed https://www.naukri.com/company-jobs Parses HTML job cards from the company's Naukri portal using scraper tags.

3. Automated Bidirectional Synchronization

The system maintains database consistency through a smart synchronization engine:

A
Jobs Registry → Partners Dashboard

If jobs are manually posted, seeded, or imported for a company that isn't in the scraper registry, a scraper configuration is automatically created with default settings upon viewing this page.

B
Partners Dashboard → Jobs Registry

Adding a company inside this dashboard automatically provisions the matching partner entity inside the main jobs database, allowing you to instantly assign manually created jobs to it.

4. Troubleshooting & Maintenance

  • High Failure Counts: If a partner's failed logs count is increasing, verify that the Careers URL is still active in your browser. Companies frequently change their ATS provider or alter their subdomain URL, requiring you to delete and re-register the partner with the updated URL.
  • Duplicate Key Errors: If seed operations show database constraint errors (e.g. key already exists), the seeder has encountered an identical job (matching title, company ID, and apply URL). The seeder automatically detects and skips duplicates to prevent corrupting the repository.
  • Scraper Interruption: Disabling a scraper pauses its execution. It will be skipped in scheduled background scraping tasks, preserving API limits. Use this for partners whose portals are undergoing maintenance.
