Everything You Need to Know About Live Connect

Frequently asked questions and technical operations breakdown

How does the Peer-to-Peer (P2P) WebRTC connection work?

VidhuraTech Live Connect utilizes WebRTC (Web Real-Time Communication) to establish a direct connection between the host and the invitees' browsers. Once the connection handshake is made via our signaling gateway, the video, audio, and code editor data flow directly between the connected peers (P2P). This eliminates middle-hop servers, providing latency that is typically 40% lower than traditional cloud-hosted video systems.

Is my camera, microphone, and workspace editor secure?

Yes. All WebRTC media streams are encrypted end-to-end (E2EE) using SRTP (Secure Real-time Transport Protocol) with AES-256 encryption. Because the media flows directly between user terminals and does not transit our server databases, it is impossible for external entities to eavesdrop on the mock evaluation or capture private code solutions.

How do candidates join without creating an account?

External candidates do not require an active VidhuraTech account to join. When you add their email addresses in the **Invites** panel and deploy the room, the system whitelist enables their browser to bypass the default landing authentication gates. They simply click the secure invite link and enter their display name to connect.

Can I compile and test code in real-time during meetings?

Absolutely. Deployed rooms feature a side-by-side Monaco code editor with syntax highlighting for 5+ languages (Python, Java, C++, JS, TS). Both candidate and host can type simultaneously. The sandbox editor compiles code inputs and prints outputs directly into the terminal window, enabling real-time algorithmic evaluations.
