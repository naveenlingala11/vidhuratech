Schema Guidelines & Rules

The catalog JSON must be formatted as an array of objects. All fields are audited by the ingestion engine before storing.

title Required string

The human-readable course name (e.g., "Intro to Kubernetes").

code Required string

Unique alphanumeric code identifier. Duplicate codes will be rejected.

level Required enum

Must be exactly: BEGINNER, INTERMEDIATE, or ADVANCED.

status Optional enum

Set draft status or publish status: DRAFT or PUBLISHED.

durationHours Optional number

Total training hours (must be 0 or positive).

price Optional number

Sales or registration price value in local currency (non-negative).

description Optional string

Full paragraph summary detailing curriculum elements.

Transactional Isolation

If any code conflicts with existing catalog items, the request will isolate duplicates while uploading the remainder.
